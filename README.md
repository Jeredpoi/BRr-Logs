# VERDICT Логи

Закрытый скрипт для logs.blackrussia.online — только для доверенных.

- Работает **только вместе с VERDICT** (основной скрипт): без него пишет «Нужен VERDICT».
- Доступ выдаёт разработчик: лист «Доступ к логам» в таблице VERDICT (да / нет / ждёт). Доступ привязан к нику в логах.
- Аналитика по нику, IP и устройству (APPMDID): с каких IP заходил игрок, кто ещё с тех же IP и устройств, провайдер и пометка «хостинг / VPN?».
- В профиле на форуме — кнопка «Проверить по логам».
- Обращения разработчику приходят в ту же таблицу с пометкой «VERDICT Логи».

Установка: открыть `verdict-logs.user.js` → Raw → Tampermonkey предложит установить.
В коде нет ключей и данных: всё, что он показывает, сайт логов отдаёт по входу самого человека.
